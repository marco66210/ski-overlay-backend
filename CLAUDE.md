# skighost

Backend FastAPI (`backend/`) de skighost.app, qui traite les vidéos de ski en overlay.

## Identité visuelle

Pour tout travail de design (pages, UI, visuels), suivre la charte dans `brand/README.md` :
- couleurs : bleu nuit `#16123F`, fuchsia magenta `#E62BF5`, blanc (tokens dans `brand/tokens.css`) ;
- police : Inter Display ; wordmark « **ski**ghost » (ski Black Italic, ghost Light Italic) ;
- logos et icônes : utiliser les fichiers de `brand/` tels quels, sans les redessiner.
